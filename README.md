One funny single-line sport the Olympics rejected — a made-up event, real
enough to sound like a broadcast, absurd enough to be funny, short enough to
fit in 200 characters.

**Entry (76 characters):**

> Synchronised Sneezing: four athletes, one pepper shaker, no tissues allowed.

## How it works

`main.ts` (Node 22, standard library only) writes the entry line to
`/output/entry.txt` (or `$ENTRY_OUTPUT` when set). No network, no
dependencies, no static badges — the three badges above are the live
make.fun badges for this competition and entry.
